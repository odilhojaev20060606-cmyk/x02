X02.0 — как выложить игру и установить её на телефон
=====================================================

Что в этой папке
----------------
index.html            — сама игра
manifest.webmanifest  — описание приложения (название, иконка, цвета)
sw.js                 — офлайн-режим: после первого открытия игра работает без интернета
icons/                — иконки приложения
fonts/                — шрифты (чтобы рукописный стиль был и без интернета)

Важно: просто открыть index.html с телефона как файл недостаточно, установка и офлайн-режим
так не заработают. Игру нужно выложить на сайт с https. Ниже бесплатный способ через GitHub Pages.


Шаг 1. Выложить игру (один раз, 10 минут)
-----------------------------------------
1. Зарегистрируйся на https://github.com (бесплатно).
2. Нажми «+» вверху справа → «New repository».
   Название, например: x02. Выбери «Public». Нажми «Create repository».
3. На странице репозитория нажми ссылку «uploading an existing file».
4. Распакуй архив и перетащи в окно браузера ВСЁ СОДЕРЖИМОЕ папки x02-pwa
   (файлы и папки icons, fonts), а не саму папку.
5. Внизу нажми «Commit changes».
6. Открой «Settings» → слева «Pages».
   В «Source» выбери «Deploy from a branch», ветка «main», папка «/ (root)» → «Save».
7. Через 1–2 минуты вверху этой страницы появится адрес вида:
   https://ТВОЙ-ЛОГИН.github.io/x02/
   Это и есть ссылка на игру. Её можно отправлять друзьям.


Шаг 2. Установить на телефон
----------------------------
Android (Chrome):
  Открой ссылку. В меню игры появится кнопка «Установить приложение».
  Если её нет: ⋮ (три точки) → «Установить приложение» или «Добавить на главный экран».

iPhone (только Safari):
  Открой ссылку → кнопка «Поделиться» (квадрат со стрелкой) → «На экран «Домой»».

Компьютер (Chrome / Edge):
  Значок установки в адресной строке справа, или кнопка «Установить приложение» в меню игры.

После установки X02.0 открывается со своей иконкой, без адресной строки, и работает без интернета.


Как обновлять игру
------------------
1. В репозитории замени index.html новым (Add file → Upload files).
2. Открой sw.js, нажми карандаш и поменяй строку
   const CACHE = "x02-v1";   →   const CACHE = "x02-v2";   (каждый раз следующее число)
3. «Commit changes». У игроков обновление подтянется при следующем открытии с интернетом.


Что хранится на телефоне
------------------------
Счёт против ботов и выбор стороны (X или O) хранятся только на этом устройстве.
