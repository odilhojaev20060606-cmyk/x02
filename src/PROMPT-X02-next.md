## 0. Контекст проекта

**Игра.** X02.0 — «ультимативные крестики-нолики» со своими правилами:
- Прелюдия 3×3: победитель получает ★, проигравший ходит первым. При ничьей бросается монетка (1% — золотая).
- Клетка N отправляет соперника на поле N.
- Свободный ход: первый ход, после проигрыша малого поля, если отправили на заполненное поле.
- ★ тратятся на «Навигатор» (1★) и «Удар» (2★). Есть тайная победа.
- Режим «Ностальгия»: обычные крестики-нолики.

**Боты** (id → имя ru):
- x1 «Лёгкий?», x2 «Уже нет», x3 «Конец» — в X02.0;
- c1 «Попробуй», c2 «Зря», c3 «Нет» — в «Ностальгии»;
- победа над «Нет» даёт обе золотые фигуры.

**Где живёт:**
- PWA на GitHub Pages: `https://odilhojaev20060606-cmyk.github.io/x02/`.
- Telegram Mini App через @xo_version2bot, прямая ссылка `https://t.me/xo_version2bot/play?startapp=...`.
- Сервер — Cloudflare Worker `https://x0-wallet.odilhojaev20060606.workers.dev`:
  - база D1 (binding `DB`), старый KV (binding `WALLET`);
  - секреты `BOT_TOKEN`, `WEBHOOK_SECRET`, `SUPPORT`.

**Файлы исходников:**
- `app.js` — весь клиент, один IIFE. Основные части:
  - `store`, `app`, `SND`;
  - бот-рожицы: `faceSVG`, `setFace`, `syncFace`, `botSay`, `armSlow`, `kickBot`;
  - рисунок «от руки»: `penStroke`, `roughRing`, `gridSVG`;
  - анимации: `animateStrike`, `flyToMain`, `confetti`;
  - экраны: `show(screen)`, конец партии `onGameEnd(r)`, ходы `doMain`, `doPrelude`, `doClassic`;
  - онлайн: `createOnline`, `joinOnline`, `onlineApply`, `shareInvite`, `pollOnline`;
  - аккаунт: `syncProfile`, `applyProfile`, `apiCall`.
- `body.html` — разметка. Экраны: `scr-menu`, `scr-x02`, `scr-classic`, `scr-wait`, `scr-shop`.
- `style.css`, `i18n.js` (ru, uz, en — у всех строк три языка), `engine.js` (правила и боты, функция `ENGINE()`).
- `tg/server.js` — исходник сервера.
  - API: `/api/login`, `/api/profile`, `/api/result`, `/api/invoice`, `/api/spend`, `/api/equip`, `/api/g/*`.
  - Webhook `/hook`, установка `/setup?key=`.
  - Таблицы: players, games, payments, meta. Схема создаётся через `ensureSchema`, в ней только `CREATE TABLE IF NOT EXISTS`.

## 1. Правила работы (обязательно)

1. **Ничего не кодить без «го».** Перед каждым этапом коротко напиши, что именно сделаешь. Если есть развилки, предложи варианты и жди «го». Правила игры без его решения не менять.
2. Токен бота никогда не просить и не показывать. Если он попал на скриншот: Revoke в BotFather → обновить секрет `BOT_TOKEN` в Cloudflare → открыть `/setup?key=…`.
3. Все новые строки добавлять в `i18n.js` на трёх языках: ru, uz (латиница), en.
4. Производительность — для слабого Android внутри Telegram WebView:
   - анимировать только `transform` и `opacity`;
   - без тяжёлых `filter: blur` на больших слоях и без live-`feTurbulence`;
   - пауза анимаций при `document.hidden`;
   - `prefers-reduced-motion` → только смена состояний, без движения.
5. Анимации не должны ломать онлайн и синхронизацию:
   - всё рисуется из разницы состояний (как сейчас в `onlineApply`);
   - если пришло несколько ходов сразу, перейти к финальному состоянию без длинной очереди анимаций;
   - ввод не блокировать дольше, чем сейчас.
6. Изменения сервера:
   - новые данные класть в **новые таблицы** (без `ALTER TABLE`);
   - все проверки делать на сервере (initData / сессия);
   - любые начисления скрепок идут через существующие функции и лимиты.
7. После каждого этапа:
   - прогнать все тесты и добавить новые;
   - сделать скриншоты телефона (390×844) и десктопа;
   - поднять версию кеша (`v13`, `v14`…).
8. Сдача этапа:
   - файлы `index.html` + `sw.js` (и новые ассеты, если появились) для GitHub;
   - `worker.js`, если менялся сервер: вставлять в Cloudflare через «перетащить файл во вкладку Safari → скопировать», потом Deploy;
   - пошаговая инструкция для BotFather, если нужна;
   - короткий список изменений.
9. В конце ответа задавай только настоящие вопросы, без дежурных.

## 3. ТЗ по пунктам

### М. Новое главное меню (согласовано 9 ноября 2026, по макетам)

**Главное требование Абдулхамида:** должно ощущаться как настоящая мобильная игра, а не как интерфейс Telegram. Дизайн один и тот же в Telegram, в браузере и в будущей версии для Google Play. Стиль тетради (бумага в клетку, рисунок от руки, шрифт Caveat) сохраняется.

**Полноэкранный режим Telegram:**
- `requestFullscreen()`, чтобы исчезла шапка «X02.0 × ⌄ ⋮»;
- только вертикальная ориентация (`lockOrientation`);
- `disableVerticalSwipes()`, чтобы игру нельзя было случайно смахнуть посреди партии;
- учитывать `safeAreaInset` / `contentSafeAreaInset`: верхние углы заняты кнопками Telegram, поэтому верх экрана с запасом;
- проверять версию через `isVersionAtLeast`; на старых клиентах работать как сейчас.

**Обложка (главный экран), сверху вниз:**
1. Справа сверху кошелёк: скрепки и монеты, у каждого зелёный «+», который открывает магазин. Рядом шестерёнка.
2. **Карточка «Профиль и друзья»** — самое заметное место. В ней:
   - аватар (если фото не загрузилось — инициалы);
   - имя без фамилии (сейчас обрезается «Одилхужайев Абдул…»);
   - короткая статистика: «2 победы · 3 друга»;
   - кружки друзей и «+» для приглашения.
   Нажатие открывает экран «Профиль и друзья».
3. **Место под баннер.** Сейчас в нём «Пройди обучение» или «Пригласи друга», позже — награда дня и турнир недели. Пустым не бывает.
4. Логотип X02.0 и бот-персонаж, с которым игроку играть следующим. Бот моргает и подкалывает фразой.
5. **Три большие «объёмные» кнопки одного размера** (при нажатии проваливаются со звуком):
   - «X02.0» — «81 клетка, звёзды, удары»;
   - «Ностальгия» — «Классика 3×3»; **у неё тот же вес, что у X02.0** (Абдулхамид считает, что в неё играют больше);
   - «Онлайн» — «С друзьями по ссылке», с красной цифрой, когда в онлайн-партии твой ход.
6. Внизу круглые иконки «Магазин» и «Об игре». В разметке заложены места ещё под две — «Задания» и «Рейтинг». **Пустые «скоро» игрокам не показывать**: кнопка появляется, когда функция готова.

**Экран режима (X02.0 или «Ностальгия»):**
- сверху кнопка «Как играть» (только в X02.0, ведёт в обучение);
- блок «С ботом» — **лестница из трёх ботов**: сверху самый сильный, снизу самый слабый. Пройденные отмечены зелёным со счётом, следующий подсвечен синим, у каждого показана награда. **Замков нет**, играть можно с любым;
- блок «С другом»: «Рядом» и «По ссылке» для этого режима.
- **Мостик в «Ностальгии»:** после нескольких побед появляется подсказка от бота «Слишком просто? Попробуй X02.0» (не сразу и не навязчиво).

**Экран «Онлайн»:**

- «Твои партии»: соперник, режим, чей ход, кнопка «Ходить» / «Открыть»;

**Экран «Профиль и друзья»:**

### Н. Новичок: бонус и обучение

- **При первом входе** — окно «Добро пожаловать!» с ботом «Нет» («Нет» уже ждёт.») и подарком **+20 скрепок**. Под ним кнопки «Пройти обучение · ещё +30» и «Позже».
- **Обучение X02.0** — 5 коротких шагов на настоящем поле, около 2 минут:
  1. прелюдия: кто выиграл — получает ★, проигравший ходит первым;
  2. клетка N отправляет соперника на поле N;
  3. захват малого поля и свободный ход;
  4. звезда и «Навигатор» (1★);
  5. «Удар» (2★).
  Каждый шаг: короткая подсказка, игрок делает ход сам, бот отвечает заготовленным ходом. Пропустить можно в любой момент.
- **+30 скрепок** за первое прохождение. Кнопка «Как играть» остаётся в X02.0 навсегда, но награда — только один раз.
- Оба бонуса выдаёт **сервер, один раз на Telegram-аккаунт** (новая таблица, например `bonuses (id INTEGER, kind TEXT, t INTEGER, PRIMARY KEY (id, kind))`). У гостя без входа — локально, а при первом входе через Telegram не выдавать повторно.
- Цифры 20 и 30 согласованы (сначала предлагалось 100 и 50, Абдулхамид счёл это слишком щедрым).

### 1. Живые боты

**Рожица** — SVG с отдельными группами: зрачки, веки, брови, рот, детали конкретного бота.

**Общее для всех:**
- моргание каждые 2–6 с, случайно;
- глаза следят за ходом: на телефоне — за последним ходом, на десктопе — за курсором над клетками; зрачок сдвигается максимум на ~2 px;
- «думает» перед ходом: зрачки перескакивают между 2–4 легальными клетками (из `E.legal`) и останавливаются на выбранной прямо перед ходом (встроить в `kickBot`);
- вздрагивает (тряска 250 мс + прищур), когда ты бьёшь его ★★ или захватываешь поле;
- радуется (подпрыгивает), когда он захватывает поле или побеждает.

**Характеры (согласовано по макету 9 ноября 2026).** Главное правило Абдулхамида: **лица уверенные и гордые, ни одного пустого или безэмоционального.** Реакции остаются, но в характере: проигрывая, бот не грустит, а злится или делает вид «тебе повезло»; выигрывая — довольно ухмыляется.
- «Лёгкий?» — бравада: улыбка до ушей, брови вверх.
- «Уже нет» — ухмылка уголком рта, одна бровь поднята, веки чуть прикрыты.
- «Конец» — **«Гроссмейстер», не робот** (антенну и квадратные глаза убрать): брови сведены к переносице, морщинка между ними, прищур-расчёт, уверенная полуулыбка. Пока думает над ходом — взгляд уходит вбок, губы «жуют» мысль, рядом точки-мысли.
- «Попробуй» — подмигивает с ухмылкой: «ну давай».
- «Зря» — скучает свысока: полуприкрытые глаза, бровь поднята, «ну-ну».
- «Нет» — **ледяная уверенность** вместо каменного лица: тяжёлые веки, едва заметная ухмылка, одна бровь чуть выше. Почти не двигается. Единственная настоящая эмоция — удивление на «…Да?».
- Состояние «думает» есть у всех ботов (они ходят с задержкой): глаза перебегают между клетками, точки-мысли. У «Конца» оно самое заметное.

**Интрига вокруг «Нет»** (согласовано). Секрет: «Нет» начинает изредка ошибаться только после 1000 поражений (`profile.netLosses`, `netCounter` в `app.js`). **Секрет и цифру 1000 не раскрывать.**
1. На карточке «Нет» в лестнице — «Твоих попыток: N» (из `netLosses`).
2. Там же общий счётчик «Победили «Нет»: K игроков». Настоящая цифра с сервера: новый лёгкий эндпоинт или поле в `/api/profile`, считать по факту получения обеих золотых за «Нет». Не писать «невозможно» — это неправда.
3. Намёки на рубежах попыток (фразы «Нет» на трёх языках, по одному разу), например: 100 — «Упрямый.», 500 — «…Зачем?», около 900 — «Почти.»
4. Значок «Победил «Нет»» в профиле, его видят друзья. Особая карточка победы (пункт Г). Обе золотые фигуры — как сейчас.

**Реализация:**
- CSS keyframes + маленький контроллер: один таймер на видимую рожицу, остановка при `document.hidden`;
- размер в шапке не меняется (`.bot-face` 42 px на телефоне);
- в онлайн-партии с другом рожица не показывается, как сейчас.

**Вес:** ≤ 0,3 МБ (только код и SVG).

### 2. Сочность ходов

- **Знак:** дорисовывается ручкой (`stroke-dashoffset`, 180–250 мс), на конце штриха клякса (появляется 0→1, потом тускнеет). Так же в прелюдии и «Ностальгии».
- **Удар ★★:** расширить `animateStrike` — зачёркивание зигзагом + 6–10 брызг чернил (≈400 мс) + тряска поля 3 px, 200 мс.
- **Захват поля:** обводка `roughRing` (уже есть) + у `flyToMain` след и «перелёт» с отскоком + 8–12 искр в месте приземления.
- **Звезда:** искра летит из клетки в счётчик ★ в шапке (координаты через getBoundingClientRect), счётчик «подпрыгивает».
- **Победа:**
  - жирная линия маркером по выигрышной линии главного поля (полупрозрачная, ~400 мс);
  - `confetti` переделать в бумажные кусочки;
  - лист «дрожит» (±0,6°, 2 раза).
- **Вибрация в Telegram:** `HapticFeedback.impactOccurred('light')` на удар и захват (есть `hapticResult` — дополнить).

**Вес:** ≤ 0,5 МБ.

### 3. Живой интерфейс

- `show(screen)` — переход как перелистывание страницы тетради:
  - CSS 3D (`perspective` + `rotateY`, ~350 мс) или более дешёвый `clip-path`;
  - при reduced-motion — простое затухание;
  - TG BackButton должен работать.

- Меню появляется лесенкой (30–40 мс на пункт), только при первом показе за сессию.
- Ожидание хода друга (`scr-wait` и чужой ход онлайн): карандаш покачивается и черкает мелкие каракули на полях; останавливается, когда ход твой.

**Вес:** ≤ 0,1 МБ.

### 4. Музыка и звук

**Треки:** меню, партия, «напряжённая концовка».
- Концовка включается, когда кому-то остаётся одно поле до победы на главном поле: есть линия с 2 своими полями и 1 свободным.
- В концовке темп плавно растёт.

**Как делать (рекомендация, согласовать):**
- Свой лоу-фай секвенсор на WebAudio: аккорды электропиано (FM/аддитивный синтез), lowpass, треск винила (шум), мягкие kick/snare/hat, свинг. Вес ~30–60 КБ, адаптивный темп делается легко.
- Если звучит дёшево — отрендерить тот же синтез в Python (numpy) → OGG/Opus 64–96 kbps, лупы 60–90 с, без щелчков на стыке.
- Чужую музыку не брать без явной лицензии (CC0) и согласия Абдулхамида.

**Звуки** (расширить `SND`):
- шорох бумаги;
- щелчок ручки;
- разный «шурх» для X (два штриха) и 0 (один круглый);
- звон звезды;
- скрежет удара.

**Управление:**
- в настройках отдельные переключатели «Музыка» и «Звуки» (`soundBtn` уже есть → добавить `musicBtn`, ключ `x02.music`);
- музыка по умолчанию тихая (~0,25) и стартует только после первого касания;
- пауза при `visibilitychange` и при сворачивании Telegram;
- во время эффектов музыка чуть приглушается.

**Приёмка:**
- нет звука до жеста пользователя;
- нет щелчков на стыках лупов;
- проверить беззвучный режим iOS;
- если появились аудиофайлы — они кешируются в sw.js.

### 5. Детали тетради

- **Каракули на полях:** набор из 16–24 маленьких SVG (звёздочка, рожица, спираль, кубик, ракета, «X0» и т.п.):
  - 2–4 на партию, только в свободных зонах — без наложения на поля и кнопки;
  - выбор по seed партии, поэтому от партии к партии они меняются.
- **Пятно от кофе:** с шансом ~30%, неровное кольцо, низкая прозрачность, под сеткой.
- **Загнутый уголок листа:** CSS.
- **Подсказка-стрелочка карандашом:**
  - когда игрока отправили на поле N, к этому полю ведёт стрелка с подписью «ход 12»;
  - это ещё и напоминает правило «клетка N → поле N»;
  - ненавязчиво, исчезает после хода.
- **Фактура бумаги:** заранее отрендеренная плитка WebP ~10–20 КБ; мягкие тени листа, без «пластмассы» и глянца.
- **Читаемость важнее всего:** проверить контраст в светлой и тёмной теме Telegram.

**Вес:** ≤ 0,5 МБ.
